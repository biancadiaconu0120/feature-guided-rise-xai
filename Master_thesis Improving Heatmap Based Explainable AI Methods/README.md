## Overview

This repository contains the implementation developed for the master's dissertation:

> **Improving Explainability of Deepfake Image Detection Using SIFT-Guided RISE Saliency Methods**

The goal of this research is to improve the quality of saliency maps generated by the **RISE (Randomized Input Sampling for Explanation)** algorithm by integrating **SIFT (Scale-Invariant Feature Transform)** information into the mask generation process.

Instead of generating completely random perturbation masks, several feature-guided sampling strategies are proposed and compared in order to obtain explanations that are:

- more faithful to the classifier,
- better localized,
- more stable,
- visually easier to interpret.

The explainability methods are evaluated on a pretrained **StyleGAN2-ADA discriminator** for the task of **real vs AI-generated face classification**.

---

# Motivation

RISE is a powerful black-box explainability method because it can explain any image classifier without requiring gradients or internal network information.

However, the original RISE algorithm samples image regions completely at random.

This means that:

- important facial structures may be sampled inefficiently,
- many masks contain mostly background,
- explanations may become noisy and poorly localized.

This project investigates whether incorporating classical computer vision features extracted with **SIFT** can guide the sampling process while preserving the model-agnostic nature of RISE.

---

# Proposed Methods

The repository contains implementations of the following methods.

## 1. Baseline RISE

Original randomized input sampling algorithm.

- Completely random masks
- Uniform sampling probability
- Standard RISE aggregation

---

## 2. SIFT-Only

Strong SIFT guidance.

Workflow:

1. Detect SIFT keypoints
2. Build SIFT density map
3. Generate masks according to SIFT density
4. Compute SIFT-mask overlap
5. Weight masks using overlap during aggregation

Goal:

Focus almost entirely on regions with rich image structure.

---

## 3. Soft-SIFT

Moderate SIFT guidance.

Workflow:

1. Extract SIFT density map
2. Slightly modify sampling probabilities
3. Preserve random mask generation
4. Standard RISE aggregation

Goal:

Balance exploration and localization.

This method achieved the best overall results in our experiments.

---

## 4. SIFT-Weighted

Instead of changing mask generation, masks receive different importance according to their overlap with the SIFT density map.

Goal:

Increase the contribution of structurally informative masks.

---

## 5. SIFT-Edge

Edge-guided mask generation.

Workflow:

- extract edge map
- generate edge-guided masks
- evaluate using RISE

Goal:

Investigate whether image edges are more informative than SIFT keypoints.

---

## 6. Adaptive Resolution

Adaptive multi-resolution mask generation.

Two configurations were evaluated:

- 16 → 32
- 16 → 48

Goal:

Combine coarse and fine spatial sampling.

### Classifier

The explainability methods are evaluated using the pretrained **StyleGAN2-ADA discriminator** provided by NVIDIA.

Official repository:
https://github.com/NVlabs/stylegan2-ada-pytorch

Pretrained network:
https://catalog.ngc.nvidia.com/orgs/nvidia/teams/research/models/stylegan2

The discriminator is wrapped into a two-class classifier using a Softmax layer to produce probabilities for **Real** and **Fake** classes.

### Dataset

The evaluation dataset consists of:

- 100 real face images from the **FFHQ (Flickr-Faces-HQ)** dataset
- 100 AI-generated face images produced using the pretrained **StyleGAN2-ADA** generator

Image resolution: **1024 × 1024**

Official FFHQ dataset:
https://github.com/NVlabs/ffhq-dataset

StyleGAN2-ADA repository:
https://github.com/NVlabs/stylegan2-ada-pytorch

- localization
- robustness
